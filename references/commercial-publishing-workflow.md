# 绘本商业化流程

把“能做出来”再往前推一步，变成“能验证、能上架、能复用”。

本流程用于概念验证和发布准备，不保证生成的文件符合任何平台的当前上架规格。提交前必须由用户核对平台的最新技术要求、内容权利和最终导出文件。

## 适用场景

- 用户明确说要做 Amazon KDP、可售书稿、系列化产品、商业测试版，或要先验证概念再重投入。
- 用户不只是要绘本内容，还要封面、描述、系列规划和排版导出链路。

## 可借鉴的流程

### 1. 先验证概念

- 先做低成本版本，不急着重做完整精装级插画。
- 先判断主题是否有购买理由，再决定是否扩图、精修和包装。
- 如果概念不成立，先换主题，不要在错误题目上堆工期。

### 2. 把整本书拆成商品链路

1. 选题与目标年龄
2. 故事结构与页数节奏
3. 角色圣经与视觉一致性
4. 逐页插图
5. 封面
6. KDP / 平台描述
7. 系列扩展
8. 排版与导出

### 3. 每一步都服务购买理由

- 选题回答“为什么家长会买”。
- 封面回答“这本书解决什么问题”。
- 描述回答“读完能得到什么好处”。
- 系列扩展回答“为什么要继续买下一本”。

### 4. 先做最小可售版本

- 先出简版样书或简版页册，再决定是否投入更高质量视觉。
- 如果样书没有反馈，优先改题目、定位或页节奏。
- 如果样书已经成立，再升级插画、封面和排版。

## 受控吸收进 skill 的内容

- 保留“选题 -> 故事 -> 角色 -> 插图 -> 封面 -> 描述 -> 系列 -> 排版”的顺序。
- 保留“先验证概念，再投入完整制作”的原则。
- 保留“封面和描述必须服务家长购买理由”的要求。
- 不把这些内容写成独立的营销课，只作为绘本工作流里的商业化分支。

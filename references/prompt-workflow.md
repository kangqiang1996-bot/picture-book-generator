# 绘本逐页提示词工作流

## 项目目录

默认在当前 workspace 创建：

```text
storybook/<book-slug>/
  00-storybook-brief.md
  01-character-style-bible.md
  02-page-plan.md
  03-cover-plan.md
  04-sample-book-notes.md
  prompts/
  images/
```

`book-slug` 使用简短英文或拼音小写，例如 `little-rain-fox`。不要覆盖旧项目。

## 出图顺序

1. 先生成封面或主角设定图，用于校准角色。
2. 生成正文前先完成逐页“因果链 + 图文契约”表，确认每页文字都能被画出来。
3. 再生成第 1-3 页，检查角色、风格、文字契约和肢体是否稳定。
4. 稳定后继续批量生成后续页。
5. 最后生成封底或扉页。

如果前 3 页角色不稳定，先修角色圣经，不继续批量生成。

## 单页提示词模板

```text
请生成一张儿童绘本插画，[比例]。

书名/项目：[书名]
页码：[封面 / 第 N 页]
读者：[年龄段]

固定角色：
[重复角色圣经中最关键的外观、服装、配饰、表情基调]

当前页画面：
[只写这一页的动作、场景、情绪、道具和镜头；一页只讲一个事件]

图文契约：
[页面文字提到的关键物件/动作/形状必须在画面中出现；逐项写清楚。例如：文字说“墙上像小手”，画面必须有墙上的小手形影子和它的来源]

肢体约束：
[有人物时写清可见手/脚数量、左右手用途、遮挡关系；例如：只露出两只手，右手托灯，左手抱小熊，不要第三只手]

页面文字：
[封面：写清必须出现的书名和副标题，并要求文字准确、清晰、无乱码。内页：如必须出现，控制在 0-12 个汉字；否则写“画面中不要出现文字，文字后期排版添加”]

风格要求：
[主风格：材质、线条、色彩、留白、适龄气质]

连续性要求：
角色外观、服装、配饰和主色调必须与前页一致；不要改变角色年龄、物种、发型、毛色、衣服颜色或核心道具。

限制：
不要照片，不要3D，不要商业海报，不要复杂 UI，不要水印，不要 logo，不要知名版权角色，不要恐怖或成人化表达，不要密集文字，不要错字乱码，不要多余手臂，不要第三只手，不要多余手指，不要肢体融合。
```

## 分镜提示结构

生成每页插图提示词时，必须包含：

- 角色档案：粘贴固定角色字段。
- 本页剧情：粘贴本页文字或一句剧情。
- 主角在做什么。
- 场景在哪里。
- 情绪是什么。
- 镜头远近。
- 色彩氛围。
- 页面文字的视觉证据是什么。
- 角色手脚数量和道具分工是什么。
- 不要出现文字，或只允许极短文字。
- 保持儿童绘本风格一致。

## 比例选择

- 方形 `1:1`：适合社媒预览、低龄绘本、单页故事。
- 横版 `4:3` 或 `16:9`：适合屏幕阅读、讲故事视频、PPT 化绘本。
- 竖版 `3:4`：适合小红书图文、手机阅读。
- 印刷绘本跨页：先做单页稳定版本，再考虑跨页构图。

## 文字策略

封面标题和副标题可以优先直接进入 image_gen，让字体、插画、光影和留白一起生成。封面文字必须短、准、可读；标题和副标题要逐字写进 prompt，并要求“无错字、无乱码、无多余文字”。生成后逐字检查，错了先重出 1-2 版，再考虑后期排版修复。

内页默认让图中无正文，正文后期排版。需要画面文字时：

- 每页 0-1 个短词，最好 2-6 个字。
- 避免诗句、长句、英文、拟声词堆叠。
- 如果生成图错字，下一版提示“画面中不要出现任何文字”。

### 正文上图的默认做法

如果用户要让图上有正文，默认不是让 image_gen 写字，而是：

1. image_gen 生成无文字插画。
2. 默认用 HTML/CSS 创建整页版式；只有用户明确要求或提供模板时才使用 PPT、PDF 或 canvas。
3. 在固定文字栏、气泡、留白区或半透明底条上添加正文。
4. 再导出带字整页 PNG/PDF。

这样可以稳定使用中文字体、避免错字，并且后续能单独改文案而不重出图。

在工作区创建 `sample-book.html`，采用：

- 每页同一比例和固定尺寸。
- 底部或侧边固定文字安全区。
- 中文字体固定，字号按年龄控制。
- 页码、标题、正文由 HTML 文本渲染。
- 插画层不含正文，只负责画面。

封面标题默认可以直接进图；内页只有道具标签、拟声小字等短文字可以尝试直接进图，失败时改回后期排版。

## 生成前检查

每个 prompt 生成前快速核对：

- 本页是否只有一个动作或发现？
- 页面文字里的关键物是否都写进“当前页画面”和“图文契约”？
- 主角是否同时做了过多动作？如果是，拆页或减少道具。
- 有人物时是否写清“只露出两只手/两只脚”和左右手用途？
- 是否需要给文字排版留白？

## 生成后检查

每页生成后先看四件事：

- 图文是否对上：文字说的小手、窗帘、灯、玩具等是否真的可见。
- 肢体是否正常：没有第三只手、多余手指、错位手臂。
- 连续性是否对上：角色服装、核心道具、房间布局没有无故变化。
- 情绪是否递进：这一页是否让故事向下一页推进。

不通过时不要继续批量生成，先重写该页 prompt 并保存为 `-v2`。

## 命名规则

```text
images/00-cover.png
images/01.png
images/02.png
images/01-v2.png
prompts/page-00-cover.md
prompts/page-01.md
```

不要覆盖旧版本。返工版本使用 `-v2`、`-v3`。

## 交付格式

生成前：

```markdown
## 绘本方案
- 书名：
- 年龄：
- 页数：
- 主角：
- 风格：

## 逐页计划
| 页码 | 画面 | 拼音 | 中文 | 英文 |
```

样书阶段补充：

```markdown
## 样书排版检查
- 页面尺寸：
- 固定字体：
- 图像安全边距：
- 文字是否压图：
- 三语正文顺序：拼音-中文-英文
- 封面、扉页、版权页、正文页是否齐全：
- PDF 导出建议：
```

生成后：

```markdown
已生成：
- 封面：images/00-cover.png
- 第 1 页：images/01.png

需要复查：
- 第 3 页角色围巾颜色略有偏差，建议重出 v2。
```

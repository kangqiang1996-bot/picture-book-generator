# 绘本创作经验

本文件记录可复用的故事、构图和版式原则，不包含参考书原文、插图、角色、文件或可还原的提取数据。只使用已获授权材料或创作实践中归纳出的抽象规律；不要机械模仿某一本作品。

## 参考处理边界

- 能用的是抽象规律，不是风格照抄：故事节奏、页面类型、文字区预留、动作可读性。
- 不要使用他人作品的版权角色、原画构图或原文案。

## 故事节奏

### 重复但升级

睡前、怕黑、胆小这类主题不要只重复同一种情绪。借鉴“每轮一个小任务”的结构：

1. 出现一个具体小麻烦。
2. 主角做一个可见动作。
3. 得到一个新发现。
4. 下一轮问题相似但略升级。
5. 最后主角主动使用学到的方法。

示例：怕黑故事可以是“看见影子 -> 用手电检查 -> 发现来源 -> 命名影子 -> 主动做影子实验”。

### 固定场景递增

同一间房、同一张床、同一扇窗反复出现，比频繁换场更适合 AI 连续绘本。

- 每页只改变一个变量：灯光、道具、角色位置、影子形状或情绪。
- 结尾回到开头场景，但情绪发生变化。
- 8 页内页建议至少 5 页留在同一核心场景。

## 页面类型轮换

不要默认每页都是满版电影感场景。根据叙事功能轮换：

- 满版场景页：建立世界、氛围或关键转折。
- 留白动作页：突出单个动作、表情或心理变化。
- 小格连续页：表现练习、重复、尝试和反馈。
- 物件特写页：解释线索、因果或发现。
- 回声页：用相似构图对比开头和结尾。

## 动作可读性

低龄绘本里，动作清楚优先于复杂光影。

每页 prompt 必须能回答：

- 主角正在做什么动作？
- 手上拿什么？只露出几只手？
- 眼睛看向哪里？
- 画面里哪一个物件解释了这一页文字？
- 这个动作如何自然引到下一页？

## 文字区前置

参考绘本常把文字放在白边、天空、墙面、页边或低信息区。生成阶段必须提前决定文字区。

- 想做左文右图：prompt 必须写“左侧 30%-35% 留白文字区，主体集中在右侧”。
- 已有满版插画：不要强行左文右图，优先整幅图 + 底部半透明文字条。
- 拼音版需要更大文字安全区；不要把拼音放在复杂背景上。

## 封面经验

封面要同时交代标题、主角、冲突/卖点。

- 标题是第一视觉层，不和副标题、徽章、星星重叠。
- 主角和核心道具可见。
- 家长能一眼看出解决的问题：怕黑、睡觉、胆小、分离等。
- 徽章只作补充，不抢主体，不压关键画面。

## 大字入画的边界

少量短句或拟声词可以成为画面节奏，但不是默认策略。

- 默认仍然后期排版正文。
- 可以入画的文字：封面标题、门牌、拟声词、短命令。
- 若采用手写大字风格，必须保留无字插画或后期排版备份。

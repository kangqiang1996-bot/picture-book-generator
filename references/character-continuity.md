# 角色与世界一致性

## 先写角色圣经

每个重要角色都用固定字段描述，之后每页提示词重复关键字段：

```markdown
## 主角
- 名字：
- 物种/年龄感：
- 身份：
- 性格：
- 体型轮廓：
- 脸部特征：
- 发型/毛色：
- 固定服装：
- 固定配饰：
- 常见表情：
- 动作习惯：
- 标志性动作：
- 手部/肢体规则：
- 适合的插画风格：
- 不能改变：
```

“不能改变”是跨页一致性的核心。比如：黄色雨衣、红色小靴子、左耳蓝色蝴蝶结、圆圆黑眼睛、背一个星星小包。

“手部/肢体规则”用于有人物的绘本页，必须写清：

- 角色正常只有两只手、两条手臂、两条腿。
- 常见拿道具方式，例如“右手托灯，左手抱小熊”。
- 被遮挡时哪些肢体不可见，例如“左手被小熊遮住，只露出手掌”。
- 禁止项：第三只手、多余手指、融合手臂、手从错误位置长出、同一只手同时拿两个远离的物体。

## 视觉锚点

每本书至少设置 3 类锚点：

- 角色锚点：服装、配饰、轮廓、颜色。
- 场景锚点：家门口的蓝邮箱、森林里的弯月树、教室窗边的绿植物。
- 道具锚点：会发光的小石头、缺角地图、红色铅笔、银色小铃铛。

锚点要足够少，少到每页都能记住；也要足够醒目，便于模型保持。

## 每页提示词重复规则

不要写：

```text
同一个小女孩继续走路
```

要写：

```text
小女孩豆豆，6岁，圆脸，黑色齐刘海，穿黄色雨衣和红色小靴子，背星星小包，继续沿着湿漉漉的小路走
```

如果角色是动物，也要固定体型、耳朵、尾巴、毛色、围巾/背包等。

有人物和道具互动时，不要只写“抱着小熊、拿着灯”。要写清楚左右手分工：

```text
豆豆只露出两只手：右手托着发光的小兔灯，左手把小熊抱在胸前；两只手位置清楚，不要第三只手，不要多余手指。
```

如果要避免手部错误，可以降低风险：

- 使用半身或中景，减少复杂交叠。
- 避免同时“拉窗帘 + 抱玩具 + 拿灯”这种三动作同页。
- 把一个动作拆到两页：先看见灯，再拉窗帘。
- 让一个道具放在床头或地上，不必每件都拿在手里。

## 镜头连续性

- 封面：主角 + 核心道具 + 世界气质。
- 前几页：中远景建立场景。
- 情绪页：近景或半身，突出表情和动作。
- 行动页：中景或广角，能看清主角做了什么。
- 结尾页：回到类似开头的构图，但让世界发生一点变化。

同一本书可以换镜头，但不要频繁大幅改变角色比例和画材质感。

## 控制变量

一次返工只改一个主要变量：

- 角色跑偏：加强角色圣经，减少场景复杂度。
- 场景跑偏：重复场景锚点，减少新道具。
- 风格跑偏：减少风格词，只保留主风格和材质。
- 文字错乱：删除画面内文字，把文字留给后期排版。
- 肢体穿帮：明确可见肢体数量、左右手用途和遮挡关系，减少道具和动作后重出当前页。

## 多角色限制

低龄绘本默认 1 个主角 + 0-2 个配角。超过 3 个重要角色时，一致性和叙事都会变差。群像故事要先合并角色功能。
